
## 5. 与 HiFi-GAN 的取舍

| | **vocos fp16** | HiFi-GAN v2 fp16（PRelu） |
|---|---:|---:|
| 硬件段 | **19.29 ms** | 62.88 ms |
| 模型 | 31.3 MB | **4.4 MB** |
| 图外步骤 | **要 iSTFT** | 不要 |
| 与同模型 CPU 相关 | 0.969–0.978 | **0.9984–0.9997** |
| 中文自然度 | 已验证试听 | **已验证试听（2026-11-02）** |

**要最快 → vocos；要省内存／去掉 iSTFT → HiFi-GAN。**（vocos 快 3.3×）

## 6. 取数要点

- **必须 CLI**：`icraft-run --dump_format HQB --dump_output`，**一句一次进程**。
  Python `forward` 连续调会第 2 句起全零。
- 输出 `v_id` 由 `json` 的 Output 节点输入给出（vocos 是 `792/796/800`，分别 `mag/cos/sin`）。
- 每份 `ftmp` 是 `513×600`，按 `T` 截断后转置成 `T×513` 再送 iSTFT。
- **取完数立刻删 dump**，否则板子根分区会被撑满（26 GB）。
